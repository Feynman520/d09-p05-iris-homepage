`/install`: 설치 화면 캡처 5장을 단계별로 + 막히는 경우 3가지 + 삭제 방법. `/privacy`: 메신저 처리방침 원문(한/영).

## 3. 조각 ③ 시각 체계 (Face 이식)

- 토큰 = Face `style.css` `:root` 그대로: base `#0a0c14` · surface `#10131d` · raised `#171b28` · overlay `#1d2233` · line `.075/.14` · ink 3단 · iris `#8fa8ff`/`#c9b8ff` · ok/warn/bad. 그림자 대신 얇은 선.
- 글꼴: Pretendard Variable(OFL, 자체 호스팅 1벌) → Segoe UI → 맑은 고딕. 본문 15px/1.65, 자간 .01em. 워드마크 = Face BRAND(Segoe Script 700, 자간 .06em, 회전 육각 마크 8초/바퀴). 모토·서명 = Nanum Pen Script(OFL, 모토 글자만 서브셋). 경로·명령만 Cascadia/D2Coding.
- 배치: 히어로만 화면 가득(별의 구 캔버스 + 도크). 아래 절들은 폭 760px 왼쪽 정렬, 절 사이 96px, 절 제목은 22px 600. 카드 남발 금지 — 기능은 Face 설정의 `.st-opt`(제목+한 줄 설명 | 오른쪽 선 아이콘) 행, 화면 캡처는 Face 헤더(48px 바 + 마크)를 두른 창 틀 안에. 이모지 0, 아이콘은 Face `icons.js` 선 아이콘(1.7).
- 움직임: 별(항상, 60fps 상한·포커스 잃으면 10fps·숨기면 정지·`prefers-reduced-motion`이면 정지 화면)과 마크 회전만. 절 등장 효과·카드 호버 효과 없음. 워드마크 두 번 클릭 = 별 서명(Face와 같은 이스터에그).
- 반응형: 400px에서도 한 열. 도크는 폭 100%−32px. 휴대폰은 별 밀도 0.5.

## 4. 조각 ④ 다운로드 단추

```text
페이지 열림 → fetch api.github.com/repos/<P03>/releases/latest (비인증, 60회/시간/IP)
   ├ 성공 → assets 중 .zip → 단추 href·판(v1.2.0)·크기(MB)·날짜, .sha256 → fetch해 값 표시(실패하면 링크만)
   └ 실패(한도·차단·오프라인) → CONFIG.fallback(마지막 판·크기·주소 releases/latest)로 그림, 판 옆에 "최신 여부 미확인" 없음 — 주소가 latest라 항상 최신으로 간다
```

- 단추 글: 「IRIS 내려받기」 + 작은 줄 `v1.2.0 · 239 MB · Windows`. 누르면 zip 직접 내려받기. 옆 작은 링크 「모든 판 보기」(Releases).
- `/download` → `/#download` 302(vercel.json). P03 설계 8-1의 "항상 최신 릴리스로 연결되는 주소 불변" 약속을 이 경로가 지킨다.
- SHA-256 확인 명령(`Get-FileHash`)을 코드 블록으로.

## 5. 조각 ⑤ 언어 전환

- `site.js`의 `I18N.en` 사전, HTML 요소에 `data-i18n="키"`. 한국어가 HTML 원문(기본), 영어는 사전에서 치환. 긴 블록(처리방침·설치 안내 문단)은 `.lang-ko`/`.lang-en` 두 벌을 두고 `html[lang]`으로 보인다.
- 첫 값 = `?lang=` → localStorage `iris.site.lang` → `navigator.language`(ko면 ko, 아니면 en). 헤더 KO/EN 토글, `<html lang>`·`<title>`도 바꾼다.

## 6. 조각 ⑥ 배포·검증

1. 로컬: `python -m http.server 8765 --bind 127.0.0.1 -d site` → 헤드리스 크로미엄으로 1280·400 폭 캡처, 콘솔 오류 0, 링크 200 확인.
2. git init → `bind-stack.ps1 -Stack A` → `gh repo create d09-p05-iris-homepage --public` → push.
3. `use-stack.ps1 A ; vercel link/deploy --prod`, 도메인 `vercel domains add iris-workspace.com`·`www`.
4. DNS는 사용자(가비아). 전파 뒤 `https://iris-workspace.com` 200·SSL 확인.
5. 배포스택 지도 1행, 메모리 갱신.
