N° 02 — WHAT IT IS

IRIS란

일이 놓일 자리와 규칙을 정해 두면, 에이전트가 그대로 일합니다.

비서에게 일을 맡기려면 세 가지가 필요합니다. 일이 놓일 자리, 일하는 규칙, 실제로 일하는 손. IRIS는 이 셋을 C:\IRIS 한 폴더에 함께 설치합니다.

01

폴더 체계

역할 → 분야 → 프로젝트 → 단계 순서로 자리를 잡습니다. 비서는 지금 어느 폴더에 있는지로 무슨 일인지 압니다.

02

규칙 파일

폴더마다 있는 AGENTS.md가 그 자리의 규칙입니다. 위 폴더의 규칙은 아래 폴더로 저절로 이어집니다.

03

에이전트와 창

Claude Code와 Codex가 실제로 일하는 손입니다. IRIS 창은 그 세션 여러 개를 한 화면에서 지휘합니다.

N° 04 — FEATURES

기능

01
세션 여러 개, 창 하나

왼쪽 작업 목록에서 세션을 오갑니다. 세션마다 폴더·에이전트·모델을 따로 기억합니다.

02
터미널과 같은 선택

에이전트·모델·사고 깊이·권한 모드는 CLI 시작 옵션으로만 넘깁니다. 설정 파일은 건드리지 않습니다.

03
대화 안 미리보기

이미지·HTML·PDF·로컬 주소를 대화 안에서 바로 봅니다. 한/글·오피스 문서는 PDF로 바꿔 그 자리에 보입니다.

04
보조 작업이 보입니다

에이전트가 띄운 보조 작업이 칩으로 보이고, 누르면 그 기록을 읽기 전용으로 봅니다.

05
완료 알림과 확인 카드

요청이 끝나면 작은 알림, 에이전트가 허락을 물으면 선택지를 카드로 보여 줍니다. 음성 입력은 PC 안에서만 처리합니다.

06
확장 모듈

설정에서 공식 모듈을 골라 설치합니다. 첫 모듈은 IRIS 메신저로, 사람끼리 글과 파일을 종단 간 암호화로 주고받습니다.

설치 3단계

  1. zip을 받은 뒤 압축을 풀기 전에 파일을 오른쪽 클릭 → 속성 → 아래쪽 「차단 해제」에 체크 → 확인. 그다음 압축을 풉니다.
  2. 풀린 폴더의 IRIS-설치.cmd를 더블클릭합니다. 파란 경고 창이나 「스마트 앱 컨트롤」 차단이 뜨면 코드 서명이 없어서입니다 — 설치 안내의 「윈도우가 막을 때」를 따라 하세요.
  3. 브라우저에 열리는 설치 화면(여덟 화면)을 따라갑니다. 정할 것은 구독과 작업 폴더 둘, 직접 할 일은 계정 로그인 하나뿐입니다.

설치는 하나, 쓰는 길은 둘

  • 바로 전부 쓰기 — 설치가 끝나면 로그인까지 이어서 합니다.
  • 창·폴더·대시보드만 먼저 — 로그인은 건너뛰고 IRIS 창부터 써 봅니다. 남은 일은 IRIS 창의 「설치 이어 하기」로 언제든 마저 합니다.

압축이 안 풀리면 파일 속성 창의 크기를 위 「자세한 정보」의 바이트 수와 견주어 보세요. 다르면 내려받기가 중간에 끊긴 것이니 다시 받으면 됩니다.

이미 설치했다면 IRIS 창의 설정 → 업데이트에서 한 번에 갱신됩니다. 새 zip을 실행해도 「업데이트 시작」이 나오고, 자료·설정·로그인은 그대로 둡니다. 1.x에서 2.0으로 넘어올 때만 새로 설치합니다(기존 자료는 그대로).

설치 안내에 화면별 설명과 막혔을 때의 대처가 있습니다.

N° 06 — INSIDE

안에 든 것

전부 C:\IRIS 한 폴더에 들어갑니다. 바깥에 생기는 것은 바탕화면 「IRIS」 바로가기 하나뿐이고, 지우려면 그 폴더를 지우면 됩니다.

부품하는 일
Node.js · Python · Git에이전트와 창이 도는 바탕입니다. 함께 들어 있어 따로 설치하지 않습니다.
Claude Code · Codex CLI실제로 일하는 에이전트입니다. Codex는 동봉되어 있고, Claude Code는 「계정 연결」 단계에서 내려받습니다. 둘 다 내 구독 계정으로 로그인합니다.
계정 중계기와 한도 화면구독 계정이 여럿이어도 한 창에서 쓰게 해 주는 작은 서버와, 계정별 사용량 화면(IRIS 창 머리의 배터리)입니다. 둘 다 PC 안에서만 돕니다.
IRIS 창세션 여러 개를 한 창에서 지휘하는 데스크톱 앱입니다. 첫 확장 모듈인 메신저도 함께 들어 있습니다.
문서 자동화 도구한/글·엑셀·파워포인트·워드·PDF를 다루는 도구 서버입니다. 한컴·오피스가 없는 PC에서는 「대기」로 두었다가, 깔면 켜집니다.
규칙 파일과 인수 문서설치기가 작업 폴더·규칙·도구 세팅을 끝내고 인수 문서를 남깁니다. 첫 실행 때 비서는 그 문서를 읽고 인사부터 합니다.

모든 소스는 MIT 허가서로 공개되어 있습니다. 동봉 부품의 허가서 목록은 zip 안 payload/licenses/NOTICES.md에 있습니다.

N° 08 — FAQ

자주 묻는 질문

유료 구독이 꼭 필요한가요?

네. IRIS는 AI를 따로 만들지 않고, 이미 쓰는 Claude 또는 ChatGPT 구독으로 Claude Code·Codex를 돌립니다. IRIS 자체는 무료입니다.

내 자료와 대화는 어디로 가나요?

내 PC 안에 남습니다. IRIS 창·중계기·설치기는 PC 밖으로 자료를 보내지 않습니다. 에이전트가 AI 회사 서버와 주고받는 내용은 각 에이전트의 정책을 따릅니다.

지우고 싶으면요?

C:\IRIS 폴더와 바탕화면 바로가기를 지우면 끝입니다. 레지스트리나 시스템 폴더에는 아무것도 쓰지 않습니다.

맥이나 리눅스에서도 되나요?

지금은 윈도우 10/11 64비트만 됩니다. 다른 운영체제는 계획에 있지만 날짜는 정하지 않았습니다.

이미 Claude Code가 설치되어 있으면 충돌하나요?

아니요. IRIS는 자기 폴더 안의 별도 사본을 쓰고, 기존 설치본과 설정에는 손대지 않습니다.

새 판이 나오면 다시 설치해야 하나요?

아니요. IRIS 창의 설정 → 업데이트에서 한 번에 갱신되고, 새 zip을 실행해도 「업데이트 시작」이 나옵니다. 어느 길이든 자료·설정·로그인은 그대로입니다. 1.x에서 2.0으로 넘어올 때만 새로 설치합니다(기존 자료는 그대로).

ChatGPT 구독만 있어도 되나요?

네. 설치기에서 ChatGPT만 고르면 Codex가 앞장섭니다. Claude Code도 함께 설치되어 IRIS 창에는 처음부터 Claude·Codex 단추가 둘 다 보이고, 나중에 Claude 구독이 생기면 한도 화면에서 계정만 더하면 됩니다.
