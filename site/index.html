IRIS란

내 일을 정의하면, 에이전트가 그 정의대로 해결합니다.

교사·연구자·사업가·개발자·직장인·학생·작가 — 어떤 일이든 방식은 같습니다. 일이 놓일 자리와 일하는 규칙을 정해 두면, 에이전트는 어느 폴더에서 열든 그 일을 알고 시작합니다.

폴더 지도 (온톨로지)

역할 → 분야 → 프로젝트 → 단계 폴더로 내 일을 나눕니다. 폴더마다 AGENTS.md 규칙이 있고, 위 폴더의 규칙은 아래로 이어집니다. IRIS 창의 온톨로지 탭에서 이 구조를 지도로 봅니다.

여러 에이전트, 같은 규칙

Claude Code와 Codex가 같은 폴더의 같은 규칙을 읽고 일합니다. 에이전트를 바꿔도 내가 정한 기준은 그대로이고, 대화 맥락도 둘 사이에 넘길 수 있습니다.

함께 설치되는 장비

한글·엑셀·파워포인트·워드·PDF 도구, “앞으로는 이렇게”를 규칙으로 쌓는 자기개선, 한도가 찬 구독 계정에서 다음 계정으로 넘어가는 계정 중계까지 함께 들어갑니다.

필요한 것

  • 윈도우 10(1809) 이상, 64비트
  • C 드라이브 여유 3 GB 이상
  • Claude(claude.ai) 또는 ChatGPT(chatgpt.com) 유료 구독 — 에이전트 CLI가 그 계정으로 일합니다

설치 3단계

  1. zip 을 내려받은 뒤 압축을 풀기 전에 zip 파일을 오른쪽 클릭 → 속성 → 아래쪽 「차단 해제」에 체크 → 확인. 그다음 압축을 풉니다.
  2. 풀린 폴더 안의 IRIS-설치.cmd 파일을 마우스로 더블클릭합니다(명령 창을 열 필요는 없습니다). 파란 경고 창이 뜨거나 "스마트 앱 컨트롤이 차단했습니다"라고 나오면 파일에 아직 코드 서명이 없어서입니다 — 설치 안내의 「윈도우가 막을 때」 순서를 위에서부터 따라가면 됩니다.
  3. 브라우저에 열리는 설치 화면(여덟 화면)을 따라갑니다. 준비 확인이 끝나면 구독과 작업 폴더 두 가지를 정하고, 설치기가 인터넷 없이 세팅을 끝냅니다. 그다음 사람이 직접 하는 일은 구독 계정 로그인 하나입니다.
받은 파일 확인하기

압축이 안 풀리면 먼저 파일의 속성 창에서 크기를 보세요. 위의 바이트 수와 다르면 내려받기가 중간에 끊긴 것이니 다시 내려받으면 됩니다. 파일 자체를 확인하려면 PowerShell에서 아래 명령의 결과를 SHA-256 값과 비교하세요.

Get-FileHash .\IRIS-Setup_v2.0.59_2026-11-10.zip -Algorithm SHA256

설치 안내에 화면별 설명과 막혔을 때의 대처가 있습니다.

자주 묻는 질문

유료 구독이 꼭 필요한가요?

네. IRIS는 에이전트를 만들지 않고, 여러분이 이미 쓰는 Claude 또는 ChatGPT 구독으로 Claude Code·Codex CLI를 돌립니다. IRIS 자체는 무료입니다.

ChatGPT 구독만 있어도 되나요?

네. 설치기에서 ChatGPT만 고르면 Codex가 앞장섭니다 — 첫 세션도, 새 세션의 기본 에이전트도 Codex입니다. Claude Code도 함께 설치해 두므로(2.0.38부터) IRIS 창에는 처음부터 Claude·Codex 단추가 둘 다 보입니다. 나중에 Claude 구독이 생기면 IRIS 창의 한도 화면에서 계정만 더하면 바로 연결됩니다.

내 자료와 대화는 어디로 가나요?

여러분의 PC 안에 남습니다. IRIS 창·중계기·설치기는 PC 밖으로 자료를 보내지 않습니다. 에이전트 CLI가 AI 회사 서버와 주고받는 내용은 각 CLI의 정책을 따릅니다.

새 판이 나오면 다시 설치해야 하나요?

아니요. IRIS 창의 설정 → 업데이트에서 한 번에 갱신되고, 새 zip을 받아 실행해도 「업데이트 시작」 단추가 나옵니다. 어느 길이든 자료·설정·로그인은 그대로 둡니다. 다만 1.x에서 2.0으로 넘어올 때는 예외입니다 — 설치 방식이 바뀌어 새로 설치합니다(기존 자료는 그대로 둡니다).

지우고 싶으면요?

C:\IRIS 폴더와 바탕화면 바로가기를 지우면 끝입니다. 레지스트리나 시스템 폴더에는 아무것도 쓰지 않습니다.
